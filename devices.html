🔌 DEVICES · flash & manage your own hardware 9 / DEV
Scope: this page manages hardware you own and control — flash firmware, open a serial console, and move files to your own ESP32/Pico/Pi/CC1101 boards over USB, SSH or SFTP. It does not log keystrokes, capture another machine's traffic, or run code on devices you don't control.

🖥 Serial console (USB)

Web Serial console. Click Connect and pick your board (Chrome/Edge desktop).\n
Talks to AT-firmware ESP-01S, MicroPython, Marauder CLI, CC1101 bridge sketches, CH340/CP210x boards. Needs a Chromium browser; the native Pi app uses pyserial.

⚡ Firmware flasher

Web builds the exact flasher command; the native app runs it (esptool.py, picotool, avrdude, dfu-util). Chrome can also flash ESP via WebSerial + esptool-js.

📁 My device fleet · file transfer (SSH / SFTP)

Transfer presets build real scp/sftp/adb push/pull commands for the selected device. Scripts run on a device only via its own shell (ssh you authenticate to) — this is remote admin of your own gear, not remote execution against third-party targets.
