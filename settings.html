🔌 Device manager — USB dongles

Active RX device
Active TX device (TX-capable only)
The native Pi app auto-detects attached hardware via lsusb, rtl_eeprom, hackrf_info and serial enumeration. RX-only adapters can't be chosen as a TX device. CC1101 and ESP-01S attach over a USB-UART bridge (CH340/CP210x) as a serial device.

🔑 API keys

Carto basemap key (Maps → Voyager layer)
WiGLE API token (Base64 of "API Name:Token" — from wigle.net → Account)
Keys are stored locally in this app only (browser storage / Pi config). The WiGLE plugin lives in the Map page; if the browser blocks its request (CORS), the native Pi app proxies it server-side.

🔒 Security & lifecycle

The lock gates app access with a code you set on first launch (stored hashed on this device), and can be re-engaged anytime from the 🔒 button in the top nav. Panic wipe erases all Kraken data stored on this device; on a native install also run uninstall.sh to remove the program, its services and any generated loot/records.
